# SeamlessArena
the is a prototype for a seamless arena experience,
designed to enhance palyers interaction and engagement on a seamless coop pvp saison . 
This project aims to provide a systems where palyers can participate in pvp  various activities
 (duels ,team matches, tournaments) .
the project aims to use the seamless coop  NETWORK implimentation to provide a vanilla duel exprience .
# Inspiration
this mod is inspired from mostly better multiplayer and other pvp mods that aim to enhance the multiplayer experience in games.

# Features 
1. Duel 1VS1 2VS2 
2. team matches 5VS5 (in the futur ) 
3 . tournaments UI modif 
4. custom Colosseums (in the futur ) a long with native Colosseums
